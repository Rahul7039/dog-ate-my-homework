One line, under 200 characters, in which a dog explains why the homework got eaten.

## The excuse

> I was grading your homework. It failed. I disposed of the evidence.

The dog isn't sorry. It was doing its job: the homework failed inspection, so the evidence had to go.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating the directory if needed) and prints it.
